# 디지털 센서 기반 과학 탐구

디지털 탐구 센서(PASCO, Vernier, 사이언스큐브, 이지메이커)를 **블루투스로 연결**해서 과학 탐구 보고서를 만드는 수업용 웹앱입니다.
설치할 프로그램이나 외부 라이브러리 없이 브라우저만 있으면 동작합니다.

## 수업 흐름

첫 화면에서 **수업을 선택**합니다. 학교급 → 학년 → 학기 → 교과서 → 단원 → 차시 순서로 고릅니다. 그다음부터 화면 위쪽에 아래 7단계가 표시됩니다.

| 단계 | 내용 |
|---|---|
| 1. 예상하기 | 실험 전 예상 질문(글 선택지, 그래프 모양 선택지)에 답하고 까닭을 씁니다. 이어서 탐구 질문과 나의 예상(가설)을 씁니다 |
| 2. 실험 설계 및 준비 | 다르게 할 것(조작 변인), 같게 할 것(통제 변인), 측정 결과(종속 변인), 준비물, 실험 과정(센서 연결~측정 포함), 실험별 안전 점검을 정합니다 |
| 3. 센서 연결 | 센서 제조사를 고르고 블루투스로 연결한 뒤 실시간 값을 확인합니다 |
| 4. 실험 및 측정 | **자동 측정**(정해진 간격·시간 동안 계속 기록)과 **수동 기록**([값 기록] 버튼을 누를 때만 기록, 거리·조건 같은 가로축 값 입력 가능) 중에서 고릅니다. 실시간 그래프, 측정 기록, CSV 내려받기가 있습니다 |
| 5. 데이터 분석 | 조건별 그래프를 겹쳐 보고 통계표를 보며 결과를 해석합니다 |
| 6. 결론 및 피드백 | 측정 그래프와 실험 전 예상을 함께 보며 결론과 성찰을 쓰고, **AI 피드백**을 받습니다 |
| 7. 보고서 작성 | A4 보고서를 확인하고 인쇄하거나 PDF로 저장합니다. 6단계에서 받은 피드백이 보고서 마지막(5. 피드백)에 들어갑니다 |

### 실험 템플릿 (js/experiments.js)
- 초등 18개 단원에 디지털 센서 실험 41개가 있습니다. 실험마다 실험 전 예상 질문, 변인, 준비물, 실험 과정, 안전 수칙이 들어 있습니다.
- 지도서 차시를 고르면 그 차시에 맞는 실험이 자동으로 선택됩니다. 예상하기 화면에서 다른 실험으로 바꿀 수도 있습니다.
- **센서가 보조인 실험(5개)**: 씨가 싹트는 조건, 식물이 자라는 조건, 온도와 기체의 부피, 물의 온도와 녹는 양, 하루 동안 태양 고도·그림자·기온 실험입니다.
  - 주요 결과를 **관찰 결과 기록** 표에 적고, 센서 데이터는 조건 확인 자료로 씁니다.
  - 데이터 분석·결론·보고서(3-1 관찰 결과, 3-2 조건 확인 데이터)와 AI 피드백도 관찰 결과를 중심으로 구성됩니다.
- 준비물과 실험 과정은 교과서 실험을 바탕으로 정리했습니다. 센서 연결부터 측정까지의 과정은 새로 작성했으니, 수업 전에 검토해 주세요.

### 초등 교과서 자료
- `source/` 폴더의 출판사별 지도서 자료로 단원 순서와 차시명을 보여 줍니다. 3·4학년은 7종, 5·6학년은 5종입니다.
- 아이스크림미디어, 천재교과서(정용재), 지학사는 지도서 차시명입니다. 나머지 출판사는 단원 학습 목표를 '활동'으로 보여 줍니다.
- 차시마다 **해당 학년 교육과정 범위 안에서** 디지털 센서로 탐구할 수 있으면 센서를 표시합니다. 예를 들어 온도 개념은 5학년 '열과 우리 생활'부터 다루고, 전압·전류·pH·전기 전도도는 초등 범위 밖이라 표시하지 않습니다.

입력한 내용은 브라우저에 자동 저장됩니다. 다른 기기로 옮기려면 **파일 저장**과 **불러오기**를 사용하세요.

## AI 피드백 평가 설정 (교사용)

[결론 및 피드백] 단계의 **AI 평가 받기** 버튼은 Claude(claude-opus-5-5)를 사용합니다. 학생의 실험 설계, 측정 데이터, 결과, 성찰을 교사의 관점에서 영역별로 평가합니다.

- 영역: 예상과 탐구 질문 / 실험 설계 / 측정과 데이터 / 결과 해석과 결론 / 평가와 성찰
- 평가 단계: 매우 잘함, 잘함, 보통, 더 노력해요
- 영역마다 잘한 점과 더 좋아지려면 할 일을 알려 주고, 마지막에 다음 탐구 제안과 교사 참고 사항을 덧붙입니다.

버튼을 누르면 보고서 내용이 Anthropic으로 전송됩니다. 학생 이름 같은 개인정보는 넣지 않습니다. 결과는 참고용이며, 사용한 만큼 Claude API 요금이 발생합니다.

### 탐구 도우미 챗봇
[실험 및 측정]과 [데이터 분석] 단계 오른쪽에 **탐구 도우미**가 있습니다. AI 평가와 같은 연결 설정을 씁니다.

- **답하는 범위**: 지금 하는 탐구(실험 방법, 센서 사용, 그래프·데이터 분석, 단원 개념)와 학생이 새로 해 보고 싶은 다른 과학 탐구를 다룹니다. 개념 설명은 해당 학년의 성취기준·해설 범위 안에서 합니다.
- **교육과정을 넘어서는 탐구**: 원리 설명 대신 탐구의 방향과 방법을 안내합니다. 측정할 수 있는 탐구 질문 만들기, 다르게·같게 할 것과 측정할 것, 쓸 수 있는 센서, 비교할 그래프를 알려 줍니다. 위험한 탐구는 안전한 대안을 제안하고, 새 탐구는 선생님 허락을 받고 하도록 안내합니다.
- **가르치는 방식**: 예상·결론의 정답이나 보고서 문장을 대신 써 주지 않습니다. 볼 곳과 생각할 질문을 제시해 스스로 생각하게 돕습니다.
- **안전**
  - 불·약품·전기 관련 질문에는 교과서 방법과 "선생님과 함께"만 안내합니다. 다쳤거나 위급하다고 하면 즉시 선생님께 알리게 합니다.
  - 개인정보 요청과 탐구와 관계없는 대화는 거절합니다.
  - 전화번호·주민등록번호 형태의 글은 보내기 전에 막습니다.
- **사용 제한**: 질문은 300자 이하로, 4초 간격을 두어야 합니다. 보고서 하나당 30회까지 물을 수 있습니다.

### 방법 1. 학교 AI 서버(프록시) — 학생 기기에 권장
API 키가 학생 기기에 저장되지 않는 방법입니다.

1. [Claude Console](https://console.anthropic.com)에서 API 키를 만듭니다.
2. [Cloudflare](https://dash.cloudflare.com)에 로그인합니다. **Workers & Pages → Create → Worker**로 새 Worker를 만들고, `proxy/claude-proxy-worker.js` 내용을 붙여 넣어 배포합니다.
3. Worker의 **Settings → Variables and Secrets**에 아래 두 값을 추가합니다.
   - `ANTHROPIC_API_KEY`: Secret 유형, 1번에서 만든 API 키
   - `ALLOWED_ORIGINS`: Text 유형, 이 앱의 주소(예: `https://trjun53.github.io`)
4. Worker 주소(예: `https://science-ai.○○○.workers.dev`)를 `js/ai-config.js`의 `proxyUrl`에 넣고 다시 배포합니다. 그러면 모든 학생 기기에서 바로 쓸 수 있습니다.

### 방법 2. API 키 직접 입력 — 교사 기기 전용
앱의 **AI 설정**에서 'API 키 직접 입력'을 고르고 키를 넣습니다. 키는 그 브라우저에만 저장되므로, 학생 기기에서는 사용하지 마세요.

## 실행 방법

Web Bluetooth는 보안 때문에 **`https://` 주소나 `localhost`에서만** 동작합니다.

- **이 PC에서 실행**: `start-server.bat`을 더블클릭하면 `http://localhost:8080`이 열립니다.
- **학생 기기에서 사용 (권장)**: 폴더 전체를 GitHub Pages, Netlify 같은 https 정적 호스팅에 올리고 주소를 공유하세요. 빌드할 필요가 없습니다.

### 지원 브라우저

| 환경 | 블루투스 센서 |
|---|---|
| Windows / macOS / 크롬북: Chrome, Edge | 지원 |
| 안드로이드: Chrome | 지원 |
| iPad / iPhone (Safari, iOS용 Chrome) | 미지원. **Bluefy** 브라우저 앱 사용 |
| Firefox | 미지원 |

블루투스가 안 될 때는 **가상 센서**로 수업 흐름을 연습하거나, 제조사 앱에서 측정한 데이터를 **파일 가져오기(CSV)**로 불러오면 됩니다.

## 센서별 지원 수준

| 제조사 | 연결 방식 | 상태 |
|---|---|---|
| **Vernier Go Direct** | 공개 프로토콜(godirect-js)을 구현했습니다. 센서 채널 이름과 단위를 자동으로 인식합니다. | 바로 사용 가능 |
| **PASCO 무선 센서** | PASCO 서비스 UUID(`4a5c000X-…`)로 연결한 뒤, 1회 측정을 요청하고 응답을 해석합니다. | **실험적**: 센서 기종마다 데이터 형식이 달라서 처음 사용할 때 확인이 필요합니다 |
| **사이언스큐브** | 범용 BLE: 서비스를 탐색하고 알림 데이터를 해석합니다. | 공개된 통신 규격이 없어 **기기 확인이 필요**합니다 |
| **이지메이커** | 범용 BLE: Nordic UART, HM-10(FFE0), ESP32 예제 UUID를 자동으로 찾습니다. | 보드가 숫자 텍스트(`23.5` 또는 `23.5,45.1`)를 보내면 바로 측정됩니다 |

### 범용 BLE 센서 설정하기 (교사용)

센서 연결 화면의 **[데이터 해석 설정]**에서 한 번만 설정하면 브라우저에 저장됩니다.

1. 센서를 연결하고 **원시 데이터**에 바이트가 들어오는지 확인합니다.
2. 데이터 형식을 고릅니다.
   - **텍스트 숫자**: `23.5,45.1`처럼 숫자가 보이면 이 형식입니다. 채널 이름과 단위만 입력하면 됩니다.
   - **바이너리**: 바이트 위치, 자료형(int16, float32 등), 엔디언, 배율을 지정합니다.
3. 센서가 시작 명령이나 값 요청을 받아야 데이터를 보낸다면 **측정 시작 명령**이나 **값 요청** 칸에 HEX 값을 넣습니다.
4. 기기 목록에 센서가 보이지 않으면 **모든 블루투스 기기 표시**를 켭니다. 서비스가 탐색되지 않으면 **추가 서비스 UUID**에 기기의 서비스 UUID를 넣습니다. UUID는 nRF Connect 같은 BLE 스캐너 앱으로 확인할 수 있습니다.

## 파일 구성

```
index.html          화면 틀
css/style.css       디자인 (인쇄용 스타일 포함)
js/curriculum.js    학교급·학년·학기별 단원, 센서 추천 규칙, 예시 질문
js/standards.js     2022 개정 초등 과학 성취기준 102개 (source/curriculum-standards.json에서 생성)
js/textbooks.js     초등 과학 교과서별 단원·차시 192개 단원 (source/단원별 핵심 내용 추출 xlsx에서 생성)
js/sensors.js       블루투스 드라이버 (Vernier, 범용 BLE, 가상 센서)
js/experiments.js   초등 디지털 센서 실험 템플릿 41개 (예상 질문, 변인, 준비물, 과정, 안전 수칙)
js/plot.js          그래프, 통계
js/ai.js            AI 피드백 평가 (Claude API, 공식 JS SDK)
js/ai-config.js     학교 AI 서버(프록시) 주소 설정
proxy/claude-proxy-worker.js  학교 AI 서버(Cloudflare Worker) — API 키를 숨기는 프록시
js/app.js           단계별 화면, 측정, 보고서
server.ps1          로컬 웹 서버 (start-server.bat에서 실행)
```

단원 목록을 학교 교과서에 맞게 바꾸려면 `js/curriculum.js`의 `CURRICULUM`을 수정하세요.
